# PhDude v1.0 Public Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1.0: frozen contracts with a stability snapshot, documented extension API with example third-party extensions under contract tests, the OpenCode host, three cross-field example workspaces proving field agnosticism, migration/extension/skill/pack/agent guides, community files, hardened CI with a Windows subset, a release workflow that publishes to npm when a token exists, and the 1.0.0 tag.

**Architecture:** No new research capability. Stabilization work only; every change is a test, a document, a workflow, an example, or the OpenCode adapter.

**Spec:** `docs/superpowers/specs/2026-09-07-phdude-v1.0-design.md`

## Global Constraints

- All prior constraints. No behavior change to stable commands without a CHANGELOG "Breaking" entry (there should be none).
- The schema-stability snapshot must be committed once and never regenerated silently: regeneration requires bumping `x-phdude.since` and a migration when required fields/enums change.
- Commit per task with the repo's trailers; do not push.

### Task 1: Contract freeze

**Files:** every `schemas/*.json` (+`x-phdude`), `tests/fixtures/schema-snapshot.json`, `tests/contracts/schema-stability.test.js`, `tests/contracts/cli-json-shape.test.js` (error shape and exit codes for each code), `docs/versioning.md`, `docs/cli.md` (stability markers), `CHANGELOG.md` ("Breaking changes since 0.1" section drafted from git history and prior CHANGELOG entries).

- [ ] Commit `chore(contracts): freeze schemas and CLI shapes with stability snapshots`.

### Task 2: Extension API docs and example extensions

**Files:** `docs/extension-api.md` (every port: purpose, signature, lifecycle, errors, stability, how to run its contract suite), `examples/extensions/{search-provider-example,document-parser-example,renderer-example,pack-example}/` (minimal, documented, MIT), `tests/contracts/example-extensions.test.js` (runs each contract suite over the examples), `docs/skills-authoring.md`, `docs/packs-authoring.md`.

- [ ] Commit `docs(extensions): extension API reference with example third-party extensions under contract tests`.

### Task 3: OpenCode host and agents guide

**Files:** `src/adapters/agents/opencode.js` (`opencodeHost`: AGENTS.md index variant + `.opencode/command/phdude*.md` from the shared templates with OpenCode front matter), `src/adapters/cli/commands/init.js` (+`opencode`; default hosts stay claude-code,codex), `tests/contracts/agent-host.test.js` (+opencode), `docs/agents.md` (Claude Code, Codex, OpenCode, Gemini CLI via AGENTS.md), README agent section, surface test.

- [ ] Commit `feat(agents): OpenCode host`.

### Task 4: Cross-field examples

**Files:** `scripts/make-examples.mjs` (profiles: quantitative-social-science, machine-learning, qualitative-humanities; reuse make-example's helpers by extracting `scripts/lib/example-builder.mjs`), `examples/{quantitative-social-science,machine-learning,qualitative-humanities}/**`, goldens per example (`status`, `next`, `gaps`, `health`, `ready`), `tests/integration/make-examples.test.js` (parity), `tests/e2e/examples.test.js` (each example: `status` ok, `health` prints eight dimensions, `ready` exits 0 or 2 deterministically), docs/examples.md.

### Task 5: Community files, CI hardening, release workflow, 1.0.0

**Files:** `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `.github/ISSUE_TEMPLATE/{bug.yml,feature.yml,config.yml}`, `.github/PULL_REQUEST_TEMPLATE.md`, `.github/dependabot.yml`, `.github/workflows/ci.yml` (matrix + windows subset + audit + pack + examples parity + permissions), `.github/workflows/release.yml` (tag-triggered; publish with provenance if `NPM_TOKEN`; GitHub release notes from CHANGELOG; `workflow_dispatch` dry run), `package.json` (1.0.0, publishConfig, keywords), `docs/migration.md`, `docs/non-goals.md`, README final pass, CHANGELOG 1.0.0.
