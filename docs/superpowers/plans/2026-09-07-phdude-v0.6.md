# PhDude v0.6 Document Factory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.6: DocumentRenderer port with Markdown (built-in), Pandoc and LaTeX adapters; venue packs (generic-thesis, IEEE, ACM) with profile checks; incremental reproducible `build`; presentation outlines and XLSX/DOCX tables; venue adaptation plans; templates registry; migration 0003.

**Architecture:** Same layering. Rendering tools are optional adapters probed with `execFile`; the built-in Markdown renderer always works. Build assembly, hashing, profile checks and adaptation plans are pure domain code; outputs live under `outputs/` and are never canonical.

**Tech Stack:** Node ≥ 22; no new dependency; Pandoc/LaTeX/rsvg-convert optional; CI installs pandoc.

**Spec:** `docs/superpowers/specs/2026-09-07-phdude-v0.6-design.md`

## Global Constraints

- All prior constraints (layering, deps, `execFile` only, atomic writes, events, strict flags, typed errors, exit codes, guard, goldens/example regeneration, surface test, skill contracts, migrations).
- `outputs/**` is derived: never read as knowledge, rebuilt from canonical inputs, ignored by `ingest`.
- A build with unchanged inputs renders nothing and appends no event.
- Workspace version → 4; migration 0003 idempotent.
