# PhDude v0.7 Reviewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.7: review objects and the review workflow with methodologist, Reviewer #2 and reproducibility skills; the citation auditor (offline + policy-gated Crossref DOI verification); explainable Research Health; `phdude ready`; external skill install under least privilege; review modes that change behavior; migration 0004.

**Architecture:** Same layering. Health, readiness and offline audit are pure functions over the snapshot and existing reports; review findings are agent judgment submitted through the CLI as entity-per-file `REVIEW-*` objects; the only network use is the Crossref DOI lookup through the v0.3 policy and http layer.

**Tech Stack:** Node ≥ 22; no new dependency.

**Spec:** `docs/superpowers/specs/2026-09-07-phdude-v0.7-design.md`

## Global Constraints

- All prior constraints. No detector/humanity scores anywhere; `health`/`ready`/`prose` refuse detector-like flags with POLICY citing PRD §30c.
- Every formula in `health` is printed with its inputs; weights come from policy with documented defaults.
- Workspace version → 5; migration 0004 idempotent.
- Commit per task with the repo's trailers; do not push.
